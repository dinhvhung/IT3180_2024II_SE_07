# Yêu cầu trang thiết bị
- Có IntelliJ (bản nào cũng được)
- Có nguồn mạng ổn định
# Hướng dẫn sử dụng
- Clone repo về
    - Mở Git Bash gõ: git clone https://github.com/dinhvhung/IT3180_2024II_SE_07.git
- Vào IntelliJ mở file ApartmentApp
- Ib trưởng nhóm để lấy file application.properties<br>
- Chạy class App
- Thông tin admin:<br>
    - Email: admin
    - Mật khẩu: admin
# Đăng ký tài khoản
- Vào giao diện đăng ký
- Nhập mã xác nhận gửi về gmail để xác thực tài khoản

- Ấn vào phần ảnh đại diện góc trên để xem thông tin người dùng
- Khi sửa thông tin, nếu thay đổi gmail sẽ phải xác thực qua mã gửi về mail
- Khi sửa mật khẩu, cần điền mã xác nhận gửi về email để xác thực mật khẩu
